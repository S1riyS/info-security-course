# Windows ЛАБ №3

**Диспетчер задач.**

Источник слайда: Л.р. №3, Xms2007@yandex.ru

Запустить диспетчер задач (`Ctrl+Alt+Del` → диспетчер задач; или выполнить `taskmgr.exe`).

Посмотреть, какие параметры процессов можно отображать (меню **Вид → Выбрать столбцы**). Отразить в отчёте список параметров и за что они отвечают (что показывают: `F1` — Help).

## Изменение приоритета задач

Запустить файловый менеджер (FAR, Total Commander и т.п.). Найти его в списке процессов (в диспетчере задач).

Изменить приоритет выполнения задачи (`far.exe` для FAR): щёлкнуть правой кнопкой по имени процесса → **Приоритет**.

Измерить время копирования файла в файловом менеджере. Провести несколько измерений для размеров 1 ГБ, 4 ГБ, 10 ГБ при разных приоритетах задачи (низкий / выше среднего / реального времени). Произвести несколько измерений для одних и тех же параметров, чтобы исключить влияние подсистемы кэширования ОС; использовать результаты второго или более позднего измерения.

Отразить в отчёте результаты измерений и параметры компьютера, на котором проводились измерения (CPU / RAM / HDD).

## Доп. задание

В FAR использовать 2 варианта: **System Settings → Use system copy routine** вкл / выкл.

## Комментарии преподавателя

- Проводником пользоваться крайне не рекомендуется.
- Файлы 10, 40 и 100 ГБ, если компьютер позволяет. Можно 10, 30 и 40 ГБ.
- Лабораторная простая, поэтому дополнительное задание нужно сделать.
